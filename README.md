## Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/WellingtonIzaias/WellingtonIzaias.github.io.git
```

Entre na pasta do projeto:

```bash
cd WellingtonIzaias.github.io
```

Instale as dependências:

```bash
npm install
```

Execute o servidor de desenvolvimento:

```bash
npm run dev
```
